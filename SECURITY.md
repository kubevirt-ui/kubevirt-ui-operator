# Security

## Supported versions

Security fixes are applied on the `main` branch and released with operator/Helm tags as they become available.

## Reporting a vulnerability

Do **not** open public GitHub issues for security-sensitive reports.

Contact the [kubevirt-ui](https://github.com/kubevirt-ui) maintainers through your organization's security channel, or open a private advisory on GitHub if enabled for this repository.

Include: affected component (Helm chart vs operator), reproduction steps, and impact (cluster scope, RBAC, console exposure).
